Fichas de fabricantes

La búsqueda revisa los nombres de fabricantes y todo el contenido de sus fichas, incluidos modelos, manuales y averías.

Cargando fichas…

Los teléfonos y enlaces deben ser públicos y verificarse antes de utilizarlos. Añade manuales solo si tienes derecho a compartirlos; es preferible enlazar a la fuente oficial.

Mantenimiento sencillo

El contenido está separado del diseño. Para añadir información, edita el archivo de datos, no el HTML.

📘 Manuales

Un registro por documento: título, modelo, revisión, idioma, fecha y enlace a la fuente autorizada.

🧰 Averías

Un registro por caso: modelo, síntoma, comprobaciones, solución y estado de verificación.

📞 Contactos

Añade departamento, teléfono o web pública, horario, fuente y fecha de verificación.

📝 Edita el archivo de datos

Abre data/fabricantes.json, busca el fabricante y añade un objeto siguiendo la plantilla de la guía.

Consejo: en GitHub usa “Edit this file” para añadir registros; revisa que cada elemento esté separado por comas y que las comillas sean dobles. La guía incluye ejemplos listos para copiar.
